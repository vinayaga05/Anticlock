# DEV SAMPLE audio, not for production

`dev-sample-tone.m4a` is a **synthetic test signal** (a chord pad plus a pulse)
generated by `scripts/generate-dev-music-sample.py`. It contains no
third-party music. The Metro dev server serves it only to development builds
(`/dev-music/*`, see `metro.config.js`). It is never `require`d by app code,
so it is not packaged into release builds.
