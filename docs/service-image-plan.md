# Service Image Plan

All new assets are square, photorealistic marketplace images with one centered, readable subject, natural warm light, a clean pale-blue or softly neutral backdrop, and no text, logos, watermarks, symbols, or UI.

Health already has natural imagery, so those assets are retained as the visual reference. The complete service-to-image plan is below; all remaining services receive a dedicated new image.
