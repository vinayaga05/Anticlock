# Anticlock Marketing Website Brief

## Analysis Summary (Step 1)

### What is Anticlock?

Anticlock is a **lifestyle super-app** combining a social video platform with a comprehensive service marketplace. It connects consumers to health, fitness, wellness, beauty, travel, and lifestyle services—all in one premium mobile experience.

### Target Audience

- **Primary**: Active, wellness-conscious consumers seeking lifestyle services, classes, bookings, products
- **Secondary**: Service providers/businesses (Health practitioners, fitness trainers, beauty salons, tour operators, course instructors, home service professionals)

### Core Problem Solved

Fragmented lifestyle service discovery and booking across multiple apps. Anticlock consolidates:
- Service discovery & booking (9 service trees)
- Social inspiration (Reels, Flash stories)
- Community building (teams, challenges)
- Direct messaging
- E-commerce (health, fitness, lifestyle products)
- AI-powered assistance

### Key Features (From Mobile App Analysis)

#### Social & Content
- **Clips (Reels)**: Vertical video feed showcasing lifestyle content, services, experiences
- **Flash**: Ephemeral stories from users and providers
- **Create**: Content creation flow for users and providers

#### Service Marketplace (9 Trees)
1. **Health**: Doctors, diagnostics, lab tests, physiotherapy
2. **Fitness**: Gyms, trainers, classes, schedules
3. **Sports**: Training, teams, competitions
4. **Wellness**: Mind-body care, holistic services
5. **Tours & Events**: Travel bookings, adventures, celebrations
6. **Beauty & Spa**: Salons, spa, beauty professionals
7. **Courses & Training**: Skills, instructors, learning paths
8. **Home Services**: On-demand home help
9. **E-commerce**: Products for health, fitness, lifestyle

#### Community & Social
- **Communities (Nexus)**: Teams, sports clubs, challenges
- **Knock**: Direct messaging between users and providers
- **Explore**: User-generated events and products

#### Provider Features
- **Become a Provider**: Onboarding flow for businesses
- **Provider Dashboard**: Business management
- **Service Applications**: Approval workflows

#### Smart Features
- **AI Assistant (Genie)**: Voice and text assistant for service discovery
- **Personalized Feed**: Interest-based recommendations
- **My Bookings/Trips/Learning/Orders**: Unified activity tracking

### Brand Identity (From Theme Analysis)

**Color Palette**:
- Primary: Aqua/Teal `#14B8A6` (trust, wellness)
- Secondary: Coral `#F97066` (energy, warmth)
- Accent palette: Lime, Sky, Lavender, Pink, Indigo, Amber (category-specific)
- Base: Deep black `#0B0B0F`, Warm white `#FAFAF7`

**Visual Style**:
- Premium, modern, colorful
- Glassmorphism, soft gradients
- Rounded corners, floating UI elements
- High contrast, bold typography
- Category-specific color coding

### Differentiators (vs. Competitors)

1. **All-in-One Lifestyle Platform**: Not just bookings or social—both plus e-commerce and communities
2. **Social-First Discovery**: Services discovered through engaging video content (Reels), not boring directories
3. **9 Service Categories**: Comprehensive lifestyle coverage from health to home services
4. **Community Building**: Teams, challenges, social connections around shared interests
5. **AI-Powered**: Smart assistant for personalized recommendations
6. **Provider-Friendly**: Built-in onboarding and business tools

### What Does NOT Exist Yet (Based on Analysis)

- Payment processing is not fully implemented in the codebase
- Some features are in development/PR stage
- App store presence not confirmed (no live URLs in codebase)
- User count, ratings, testimonials are mock data

### Content Strategy for Website

**DO**:
- Showcase the vision and capabilities
- Use app's actual feature names and categories
- Highlight social + marketplace combination
- Emphasize premium lifestyle brand positioning
- Show service tree coverage
- Explain provider onboarding

**DON'T**:
- Claim payment processing or transactions
- Invent user statistics or ratings
- Make up testimonials
- Provide fake contact details
- Create legal text
- Promise app store availability (use "Coming soon" until URLs provided)

### Technical Stack (Mobile App)

- React Native 0.86
- Navigation: React Navigation with custom floating pill tab bar
- State: Zustand, React Query
- Themes: Dark/light mode support
- Backend: Hono API + Drizzle ORM + PostgreSQL
- Media: Cloudflare R2 for videos

### Marketing Website Goals

1. **Attract users**: Show the app's unique value, drive app downloads when available
2. **Attract providers**: Explain business opportunities, drive provider applications
3. **Establish brand**: Premium, trustworthy, comprehensive lifestyle platform
4. **SEO**: Rank for lifestyle services, wellness bookings, etc.
